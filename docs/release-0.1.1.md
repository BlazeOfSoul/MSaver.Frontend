# MSaver 0.1.1

9 сентября 2026 года.

- Из сводки переводов всех счетов удалены графики. Точные суммы поступлений,
  отправлений и изменения сохранены в компактных таблицах по валютам.
- Редактирование счёта использует общий `NameColorDialogComponent` с тем же
  колорпикером, что категории и теги. Цвет сохраняется существующим API в БД.
- Версия PWA повышена до 0.1.1.
- Тест стилей кнопок больше не зависит от переводов строк Windows/Linux.

Причина ошибки сеансов на production: фронт был опубликован, а backend master
оставался на `0ff1cb4`, без маршрута `/api/Auth/sessions` (ответ 404).
Подготовленный backend `4ab0538` опубликован и прошёл GitHub CI/deploy.
После выпуска маршрут возвращает ожидаемый 401 без авторизации.

Проверки: чистая установка npm, 512 тестов фронтенда, production-сборка и бюджеты
69 CSS-файлов в Linux/Node 22; 346 тестов бэкенда; 16 интеграционных сценариев на
изолированном PostgreSQL, включая список сеансов, изоляцию владельцев и немедленный
отзыв доступа. Ручная проверка общего диалога и таблиц переводов.
