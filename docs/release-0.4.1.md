# MSaver 0.4.1

18 ноября 2026 года.

- Цвет доступен при создании любого счёта. Начальный баланс проверяется до отправки с учётом точности валюты.
- Ошибки сохранения счёта, категории и тега остаются в форме вместе с введёнными данными. Успешная смена имени или цвета счёта обновляет загруженные данные без повторной загрузки журнала и балансов.
- Годовые балансы загружаются при выборе «Год» в аналитике. Месячный и годовой экраны используют один запрос на баланс конкретного счёта и месяца.
- Сохранение описания операции обновляет запись на месте. При активном поиске перечитывается только нужная страница журнала. Запрос сохраняет исходное время операции, если оно не менялось в форме.
- После создания категории теги остаются в кэше. Детали тегов загружаются до четырёх одновременно с сохранением порядка.
- Журнал при смене месяца вне своей вкладки обновляется при возвращении к нему.

Версия PWA обновлена до 0.4.1. Изменения бэкенда и миграции не нужны. Запись добавлена в «Настройки → Дневник разработчика».

Проверено 569 тестов, production-сборка, ограничения CSS и прокрутка. В локальном браузере с тремя счетами и шестью тегами открытие месячной аналитики сократилось с 40 до 7 запросов. После правки описания без поиска остаётся только запрос на сохранение. Создание непривязанной категории больше не отправляет семь запросов за тегами. При переключении месяца во время годовой загрузки одинаковые балансы запрашиваются один раз.
