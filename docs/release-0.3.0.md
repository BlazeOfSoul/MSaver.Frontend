# MSaver 0.3.0

## Изменения

- Четыре денежных показателя в верхней сводке: баланс, баланс после закрытия долгов, доходы и расходы. Количество операций перенесено в заголовок журнала и учитывает весь результат фильтрации, а не только текущую страницу.
- Единый блок «Баланс по счетам» с переключением валют, общим остатком, изменением за месяц и сравнением счетов. «Движение по счетам» раскрывает поступления, списания, переводы и максимальный остаток внутри месяца.
- До четырёх валют переключаются кнопками; при большем количестве используется компактный список с поиском по коду и названию. Показаны только валюты счетов, соответствующих текущему фильтру.
- Максимум рассчитывается по полной истории операций и начальному остатку. Поступление с последующим переводом больше не скрывает промежуточный пик.
- В настройках можно выбрать доход или расход для новых транзакций. Выбор сохраняется отдельно для пользователя в текущем браузере.
- Плановые операции можно редактировать через существующий `PUT /api/recurring-transactions/{id}`. Если дата не менялась, сохраняются исходные момент времени, часовой пояс и день месяца.
- Исправлены наведение и выбор сегментов месячных диаграмм и горизонтальных графиков счетов.
- Упрощён блок уведомлений, обновлены активные сеансы. На телефонах устранено переполнение верхней панели, кнопки плановых операций выровнены в сетку.

## Обновление установленного приложения

Версия в `package.json`, `package-lock.json` и `ngsw-config.json` — 0.3.0.
Production-сборка создаёт новый `ngsw.json`. После публикации и загрузки новой
версии существующий механизм `VERSION_READY` показывает баннер
«Доступна новая версия MSaver» с кнопкой «Обновить».
Автоматической перезагрузки нет; пользователь может сначала сохранить ввод.

Проверка обновления выполняется после запуска, возвращения в приложение,
восстановления соединения и каждый час. Это уведомление внутри приложения;
закрытое или отключённое от сети приложение увидит обновление при следующем
подключении. Миграции данных и изменения бэкенда для этого выпуска не нужны.

## Проверка перед публикацией

- Полный набор тестов фронтенда, production-сборка, проверки размеров CSS и прокрутки.
- Проверка `dist/MSaver/browser/ngsw.json`: версия 0.3.0.
- Ручная проверка сводки и переключения валют в локальном браузере на тестовых данных, включая мобильную ширину.

Публикация выполняется только после подтверждения владельца. Push в `master`
запускает существующий workflow проверки и развёртывания фронтенда.
