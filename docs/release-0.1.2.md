# MSaver 0.1.2

- Таблицы переводов по валютам используют одинаковую ширину столбцов. На телефоне сохраняется отображение строк карточками.
- Удаление счёта требует подтверждения с его названием и объяснением архивации. По умолчанию фокус на отмене; отмена, Escape и нажатие на фон не удаляют счёт.
- Форма создания счёта закрывается после успешного ответа API. При ошибке сохраняются форма, введённые данные и сообщение сервера.
- Все модальные окна, включая создание первого счёта, используют общий фон с одинаковым затемнением и размытием.
- Версия PWA повышена до 0.1.2. Контракт API и схема базы не изменены.

Проверено: 520 тестов, проверки прокрутки и размеров стилей, production-сборка. В локальном браузере проверены создание, ошибка дубликата, отмена и подтверждение удаления; выравнивание таблиц при ширине 1250 px; таблицы и диалог при 360 px; светлая и тёмная темы. Временный тестовый счёт после проверки архивирован в локальной QA-базе.
